## No test makes a live API call

Asserted by this script, which fails if any test file references a
real transport (`httpx.AsyncHTTPTransport`, `socket`, `requests`,
`urllib.request`). Every test drives the real client over an injected
`httpx.MockTransport` or a recorded cassette, so the retry loop,
timeouts and pooling under test are the real ones and only the socket
is replaced.

This is a design requirement rather than a convenience: a suite whose
result depends on a third party's uptime and a non-deterministic
sampler is a status page, not a test suite.

## Limitations

- **Test count is not coverage.** This file says how many tests exist
  and that none dials out. It says nothing about which branches they
  reach; no coverage measurement is committed here.
- The network audit is a static grep over test files. It would not
  catch a live call made from a helper imported out of `src/`.
- Cassettes prove the client parses what a server *did* send, not that
  any provider still sends it. A re-record is the only way to know.
